## 🎨 品牌与视觉

- **更名为「喵账本 MeowLedger」**，明确**个人记账平台**定位——报刊编辑部只是视觉语言，导航与文案全部回到记账口径：本月账本 / 收支流水 / 统计报表 / 记账单 / 账本设置。
- **完整实体猫标识**：左上角徽章、favicon、PWA 图标统一为 AI 手绘的**完整全身橘猫抱账本**实体贴纸（透明 alpha WebP），左上角、桌面图标、GitHub 封面三处完全一致。
- **全站猫咪统一为主编猫「墨墨」的多姿势插画**：读报（报头）、蜷睡（空态）、挥手（侧栏/便签/设置）、抱存钱罐（储蓄目标），透明 WebP 合计约 268KB。
- **复古报刊改版**：SVG 噪点纸纹、胶带、邮票齿孔、楷体铅笔批注、报纸双线分栏；报头「墨账日报 → 喵账本」+ 手绘主编猫 + 日期期号邮戳。
- **全部图标重绘为手绘多彩贴纸风**（彩色填充 + 深棕描边 + 微歪线条），新增猫/爪印/铃铛/日历/同步/撤销/排序/书签等 30+ 键；旧数据自定义图标与 emoji 仍兼容。
- **双主题**：默认「日刊」（米白报纸），另有「夜班」（编辑部台灯暖棕暗色）；图表色板走 `--chart-1..8` 随主题重渲染。新增 `#dark` / `#light` 深链。

## 🧾 记账能力

- **月度分类预算 + 信封式结转**：未用完额度滚入下月、超支扣减后续信封；首页预算卡实时按信封口径展示。
- **储蓄目标**：进度条、按目标月倒推月存额、首页快捷存入（纯进度追踪，不影响余额）。
- **周期账单 / 订阅管理**：每月/每季/每年扣费与扣费日，首页到期提醒（逾期标红），一键缴账并自动顺延。
- **自动归类规则引擎**：按顺序匹配商户/商品关键词归类，导入与手动记账均生效，记账时智能预选分类。
- **资产走势 + 年度总览**：月度净值曲线、当前总资产（含信用卡负债）、年度总收支/结余/月均与 12 月收支柱状图。
- **标签增强**：统计标签排行 + 记账标签自动补全（高频 Top 20）。
- **微信/支付宝账单导入**：CSV（含 GBK 老版本）与新版 xlsx 自动分流，识别来源账户、按规则归类、跳过重复。
- **算式金额输入**：金额框支持 `12+8`、`(30+6)/2`，失焦自动求值。

## ⚡ 工作流与交互

- **破坏性操作全面可撤销**：删除单笔/批量账目、账户、分类（含级联预算与规则）、周期账单、储蓄目标，以及清空、导入、缴账、存入，完成后提示条一键「撤销」；采用操作级恢复，不覆盖撤销前的其它编辑。
- **主题化确认框**：危险操作走「审稿签」弹层（`alertdialog` 语义、焦点默认取消、Esc/回车取消、关闭归还焦点），替代浏览器原生 `confirm`。
- **流水实时排序 + 批量选择删除 + 保存视图**：四种排序、勾选/全选/整批删除并整批撤销、常用「筛选+排序」收藏为命名快捷方式（跨月复用）。
- **键盘快捷键**：`N` 记一笔、`/` 聚焦搜索、`Esc` 关闭弹层。
- **PWA 快捷方式 + URL 快速记账**：长按图标直达记账；`?type=expense&amount=30&payee=xx&tag=a,b` 参数预填。
- **一键打印报告**：隐藏交互组件、自动切换浅色打印配色。

## ☁️ 数据与部署

- **GitHub 私有仓库同步**：账目/预算/规则/目标随私有仓库同步，纯前端、无自建后端。
- **数据自持**：localStorage 本地存储 + JSON 备份 + 账目 CSV 导出（UTF-8 + BOM，Excel 不乱码）。
- **离线 PWA**：Service Worker 预缓存外壳，当前缓存版本 `meowledger-v1.10.1`。
- **零迁移兼容**：全程主账本 key、导出文件名、GitHub 数据仓库名、npm 包名、仓库 slug 保持不变；保存视图存储键自动从旧键无损迁移。
